# Мифы маркетинга

Обзор доказательств по бытовым темам: еда, БАДы, косметика, бытовая химия, одежда, спорт, медицина, экология, гаджеты, никотин. По каждой теме — вердикт, размер эффекта и цена вопроса.

**Сайт:** https://folgabes.github.io/marketing-myths/

## Легенда

🟢 работает, стоит денег · 🟡 не вредно, но переплата · 🔴 не работает или вредно · ⚪️ данных нет

Ключевое различие, которое отчёт старается выдерживать: **🔴 «доказано, что не работает» ≠ ⚪️ «плохо изучено»**.

## Как это сделано

Версия 1, октябрь 2026. Текст собран с помощью ИИ (Claude) по открытым источникам. Проверка выборочная: часть цифр и названий исследований сверена с первоисточниками, часть — нет. Что проверялось и что было исправлено — в файле [content/34-corrections.md](content/34-corrections.md).

Это обзор доказательств, а не медицинские назначения.
